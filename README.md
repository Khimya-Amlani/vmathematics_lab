# Mathematics Lab in Action

Static site, no build step. Deploy the whole folder.

- Vercel: drag this folder onto vercel.com/new (or `npx vercel --prod` inside it).
- Netlify: drag the folder onto app.netlify.com/drop.
- GitHub Pages: push to a repo, Settings → Pages → deploy from branch (root).

Structure
- index.html                     hub page (journey + s-plane demo)
- labs/fourier.html              Fourier series & transform
- labs/laplace.html              Laplace explorer
- labs/laplace-vs-fourier.html   Case study: chord, spectrum vs poles
- labs/anc.html                  Active noise cancellation
- labs/svd.html                  SVD image compression
- labs/orthogonal-trajectories.html

Edit the credits in the footer of index.html before submitting.
